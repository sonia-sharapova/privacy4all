WHY IT MATTERS

Every request you make, every cookie you accept, and every extension you install passes through your browser first. It is the widest attack surface most people carry every day.

"The browser you choose says more about your privacy posture than any single setting you toggle inside it."

RECOMMENDED BROWSERS

Judged on usability, privacy, customizability, philosophy, respect for the user, looks, and resource usage.

Brave
Desktop, Android, iOS

Blocks ads, trackers, and fingerprinting by default and supports Global Privacy Control out of the box. Chrome-based, so it supports Chrome extensions.

Download browser →
DuckDuckGo
Desktop, Android, iOS

There is hesitance among users about AI features, but allegedly they can be turned off. No extensions on desktop, but the search engine can run on Firefox.

Download search engine →
Mullvad Browser
Desktop

Blocks ads, trackers, and fingerprinting by default and supports Global Privacy Control out of the box. Firefox-based.

Download browser and/or VPN →
Safari
iOS, macOS

Recommended for iOS by Privacy Guides, and now supports uBlock Origin as of August 2025.

Read more →
Firefox
Desktop

Questionable telemetry (snooping), especially with AI features, but a solid option if manual configurations are applied.

Hardening instructions →
LibreWolf
Desktop

A privacy-hardened version of Firefox with Mozilla's telemetry stripped out and uBlock Origin included by default.

Download →
Tor Browser
Desktop, Android

Maximum anonymity by routing traffic through volunteer relays, at a real speed cost. Best for the moments that call for it.

CHOOSE YOUR BROWSER LINEUP

Ideally, you shouldn't rely on a single browser. Instead, install two or three and use each for a different purpose — one for everyday browsing with strong protections, one as a "throwaway" for risky extensions or low-value logins, and optionally one kept completely clean as a fallback.

MAIN BROWSER
  • Daily browsing
  • Banking
  • Email
  • Social media
  • Work
RECOMMENDATION
LibreWolf or Brave
THROWAWAY BROWSER
  • Shopping
  • Coupon sites
  • One-off logins
  • Risky links
  • Sketchy sites
RECOMMENDATION
Brave (with extensions you don't trust)
BACKUP
  • Clean, no add-ons
  • For broken sites
RECOMMENDATION
Safari or Edge
Step-by-Step Setup
STEP 1
Install your main browser
  • Download from the official website, not a third-party download site
  • Set it as your default browser in your OS settings
STEP 2
Install your throwaway browser
  • Use it for anything you don't want in your main browser profile
  • Install extensions that might be risky, like coupon finders
  • Never log in to your main accounts here
STEP 3 — OPTIONAL
Keep a clean backup
  • Leave this browser completely unmodified
  • Try it when a site breaks in your main browser
  • This is your "canary" for whether a site is broken or over-blocked
