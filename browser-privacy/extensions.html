Browser Extensions

FILE NO. 015
REV. 2026–08
READ TIME 5 MIN
WHY IT MATTERS

Every extension is a piece of code with broad access to what you see and type. Where a setting can do the job instead of an extension, prefer the setting — keep the list deliberately short.

"Install as few extensions as possible. A minimal, well-audited set beats a long list of unaudited convenience tools."

STEP-BY-STEP CONFIGURATION

Every browser's privacy settings live in a different place. Pick yours below.

Step 1 — Enhanced Tracking Protection
about:preferences#privacy

Action: select "Strict" (instead of Standard or Custom). Why: blocks most trackers and enables Firefox's fingerprinting protection automatically.

Step 2 — Turn Off Telemetry

On the same about:preferences#privacy page, scroll to "Firefox Data Collection and Use" and uncheck all four boxes: technical/interaction data, personalized extension recommendations, study installs, and backlogged crash reports.

Step 3 — DNS over HTTPS
about:preferences#general

Action: scroll to "Network Settings," click Settings, and enable DNS over HTTPS — pick NextDNS if you also want ad/tracker blocking at the DNS level, or Cloudflare for a simpler option.

+ Advanced: Certificate Authorities

Advanced — only for users comfortable editing low-level browser settings.

Certificate Authorities

Scroll to "Certificates" on the privacy page, click View Certificates → Authorities. Consider removing certificate authorities you don't trust (this guide flags TrustCor and Chinese government-linked CAs specifically).

Block Firefox's Own Telemetry Server

Block telemetry.mozilla.org at the DNS level through your router or a DNS filtering service, as an extra layer beyond the in-browser toggles.

Step 1 — Shields
brave://settings/shields

Action: confirm ad and tracker blocking is active on all sites (Settings → Shields also works). Why: it's on by default, but worth a quick check.

Step 2 — Block Notification Requests

Go to Settings → Additional settings → Privacy and security → Site and Shields Settings → Notifications, and set it to block sites from asking for notification permission.

Step 3 — Social Media Blocking
brave://settings/socialBlocking

Action: disable Google and Facebook login/social widgets if you don't use them.

Step 4 — Confirm Global Privacy Control

Visit globalprivacycontrol.org to confirm it's working — Brave supports this by default. See Part 4: Test & Verify for how to read the result.

If you can't fully leave Chrome (work requirements, specific extensions, etc.), do at least the following.

Step 1 — Disable Enhanced Spellcheck
chrome://settings/?search=Enhanced+Spell+Check

Why: with Enhanced Spellcheck on, Chrome can send the text you type in web forms — including passwords in some cases — to Google's servers for spell-checking.

Step 2 — Clear Site Data Periodically
chrome://settings/siteData

Action: click Remove All periodically to clear cookies and site data.

Step 3 — Skip Cloud Spellcheck Extensions

Don't install Microsoft Editor or similar cloud-spellcheck extensions in Chrome or Edge, for the same reason as Step 1.

+ Advanced: what Incognito and on-device AI mean for you
Incognito Isn't Private

Incognito Mode only hides your activity from other people using the same device. It does not stop Google, your internet provider, or the websites you visit from logging what you do, and Google's own employees have acknowledged its privacy limits fall short of what users expect.

On-Device AI Downloads

As of May 2026, Chrome downloads a roughly 4GB file to support on-device AI features without a clear notification to the user; if disk space or bandwidth is a concern, check Chrome's AI/on-device model settings and disable this if you don't need it.

Not using Firefox, Brave, or Chrome? The same handful of settings apply almost everywhere — look for these in your browser's privacy or settings menu.

  1. Enable the strictest built-in tracking protection option available.
  2. Turn off any "usage data," "telemetry," or "diagnostics" sharing toggle.
  3. Turn off autofill for addresses and payment cards if you don't want the browser storing that information.
  4. Turn off search suggestions that send your keystrokes to a server as you type.
  5. Enable HTTPS-only mode if the browser offers it.
  6. Set a private search engine as default (see Part 1).

INSTALL A MINIMAL SET OF PRIVACY EXTENSIONS

uBlock Origin — top pick across every source consulted

Blocks ads and trackers, and is widely regarded as the most effective and best-maintained blocker available.

Install for Firefox Install for Chrome Install for Brave
  1. Go to the extension store for your browser (Firefox Add-ons, Chrome Web Store, or Brave/Edge's respective stores).
  2. Search for "uBlock Origin" and confirm the developer listed is Raymond Hill, also known as gorhill. Do not install look-alikes such as "uBlock" (no "Origin") or "uBlock Pro," and note that it has no connection to the website "ublock.org."
  3. Click Install/Add to Browser.
  4. If you're on Chrome specifically: Google disabled the original uBlock Origin for most Chrome users in 2025 as part of the Manifest V3 changes. Install uBlock Origin Lite instead (also by Raymond Hill) if the full version isn't available to you. Firefox and Firefox-based browsers like LibreWolf still support the full, more capable version.
  5. If you use Mullvad Browser, you can skip this step: uBlock Origin comes built in.

Privacy Badger (by the Electronic Frontier Foundation)

Learns which trackers are following you across sites and blocks them, with almost no configuration needed.

  1. Search your browser's extension store for "Privacy Badger" and confirm the publisher is the EFF (Electronic Frontier Foundation).
  2. Install it and leave it running in the background; it needs no setup.

Note it currently doesn't work on Safari (macOS or iOS), though the EFF was working on Safari support as of June 2025.

Decentraleyes

Serves common website code libraries locally instead of letting your browser fetch them from Google or other third-party servers, which reduces one common way sites can track you across the web.

  1. Search your browser's extension store for "Decentraleyes" and install it.
  2. No configuration is required after installation.

Facebook Container (Firefox and LibreWolf only)

Isolates Facebook in its own contained tab so it can't track your activity on other websites you visit.

  1. Search Firefox Add-ons for "Facebook Container" (made by Mozilla) and install it.
  2. After installation, any Facebook tab automatically opens in an isolated container; no further setup needed.

Disable HTML5 Autoplay

Stops videos on websites from automatically starting with sound.

  1. Search your extension store for "Disable HTML5 Autoplay" and install it.
  2. Optionally review its settings to allowlist specific sites where you do want autoplay.

CHECKPOINT Red Flags — When to Avoid an Extension

Never install an extension that shows one of these signs. Click each to see why it matters.

Asks for "Read and change all your data on websites you visit" for no clear reason

Legitimate ad/tracker blockers need this permission to work. A note-taking app, theme, or unrelated utility asking for it has no good reason to — that's the warning sign.

Has few users but many glowing reviews

Fake or paid reviews are a common way to disguise a rushed or malicious extension launch. A low install count with a wall of five-star reviews rarely adds up naturally.

Was recently bought by an unknown company

A well-regarded extension can turn hostile overnight after an acquisition. Check the changelog and reviews around the sale date before trusting an update from a new owner.

Hasn't been updated in over a year

Unmaintained extensions accumulate unpatched security holes as browsers change their APIs underneath them.

Comes from a third-party website, not the official store

Store review processes catch obvious malware before it reaches you. A sideloaded file skips that check entirely.

Has a name that mimics a popular extension

E.g. "uBlock" vs "uBlock Origin." Copycats piggyback on a trusted name's search ranking to catch users who don't check the developer.
