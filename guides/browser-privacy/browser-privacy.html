Browser Privacy

General Privacy Habits (Browser)

  1. Never use “Log in with Google” or “Log in with Facebook” on other websites. It links your activity on that site back to your Google or Facebook account. Create a separate account (with a password manager to keep track of it) for each site instead.
  2. When a website asks for permission to send notifications, decline by default. Scam and malware campaigns frequently abuse browser notifications, and most legitimate sites don’t need this permission.
  3. Periodically clear cookies and site data: in Chrome or Brave, go to chrome://settings/siteData and click Remove All; in Firefox or LibreWolf, go to about:preferences#privacy and click Clear Data. Firefox and LibreWolf can also be set to do this automatically on every shutdown from the same settings panel.
  4. Remember that private/incognito windows only hide your history from other people using your device. They do not hide your activity from your internet provider, the websites you visit, or (in Google’s case) from Google itself.

Part 1Choose the Right Browser(s)

Ideally, you should not rely on a single browser. Instead, install two or three and use each for a different purpose:

  • one for everyday browsing with strong protections
  • one as a “throwaway” for risky extensions or low-value logins
  • (optionally) one kept completely clean so you always have a working browser to fall back on if a website breaks

Judging criteria:

  • usability
  • privacy
  • customizability
  • philosophy
  • respect for the user
  • looks
  • resource usage

Part 2Choose a Private Search Engine

Search engines see every question you type, often before you even visit a website, so this pairs directly with your browser choice.

Privacy search engines

  1. Brave Search: a US-based, privacy-focused search engine launched in June 2021. If you use Brave browser, it’s already available as a default option in Settings → Search Engine.
  2. Mojeek: a European search engine that operates under European privacy law. Add it in your browser’s search engine settings by searching for “Mojeek” in the list, or manually add mojeek.com as a custom search engine.
  3. SearXNG: an open-source search tool that pulls results from multiple search engines without tracking you; since it’s self-hostable, you can also use one of the public instances listed at searx.space if you don’t want to run your own.

To set any of these as your default: in Firefox/LibreWolf go to about:preferences#search; in Brave or Chrome go to Settings → Search Engine; select the engine you’ve added from the dropdown.

Part 3Install a Minimal Set of Privacy Extensions

Important Note: install as few extensions as possible, because every extension is a piece of code with broad access to what you see and type. Where a setting can do the job instead of an extension, prefer the setting. The list below is deliberately short.

uBlock Origin (top pick across every source consulted)

Blocks ads and trackers, and is widely regarded as the most effective and best-maintained blocker available.

  1. Go to the extension store for your browser (Firefox Add-ons, Chrome Web Store, or Brave/Edge’s respective stores).
  2. Search for “uBlock Origin” and confirm the developer listed is Raymond Hill, also known as gorhill. Do not install look-alikes such as “uBlock” (no “Origin”) or “uBlock Pro,” and note that it has no connection to the website “ublock.org.”
  3. Click Install/Add to Browser.
  4. If you’re on Chrome specifically: Google disabled the original uBlock Origin due to the Manifest V3 changes. Install uBlock Origin Lite instead (also by the same developer). Firefox and Firefox-based browsers like LibreWolf still support the full version.

Browser Extensions

  • Decentraleyes Protects against tracking with a local CDN (Content Delivery Network) emulation.
  • Privacy Badger Privacy Badger blocks spying ads and invisible trackers.
  • HTTPS Everywhere HTTPS Everywhere is a Firefox, Chrome, and Opera extension that encrypts your communications with many major websites, making your browsing more secure.
  • uBlock Origin An efficient blocker for Chromium and Firefox. Fast and lean.
  • TamperMonkey The world’s most popular userscript manager.
  • WebRTC Network Limiter Configures how WebRTC’s network traffic is routed by changing Chrome’s privacy settings.
  • ScriptSafe A browser extension that gives users control of the web and more secure browsing while emphasizing simplicity and intuitiveness.
  • NoScript Allow active content to run only from sites you trust, and protect yourself against XSS and clickjacking attacks. Firefox only.
  • Bureaucracy Read the news without subscribing, bypass the paywall.
  • Universal Bypass Universal Bypass automatically skips annoying link shorteners.
  • Violentmonkey An open-source userscript manager.
  • Anti-Paywall A browser extension that maximizes the chances of bypassing paywalls.
  • Google Unlocked Uncensor google search results.
